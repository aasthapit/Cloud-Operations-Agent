3How to read these in a demo

Five talking points this capture supports:

  • Deterministic first: every value above came from a versioned check battery (config, not code) executed before any model ran; the narrative can only cite what exists here.
  • Platform or app: healthy attestation + critical report answers the first triage question with evidence, in under a second of checks.
  • Auditable healthy: even passing checks carry their tool, args, timestamp, and runbook; a green verdict can be defended row by row.
  • Vanilla and OpenShift: the same battery runs on both; what does not apply says so instead of lying in either direction.
  • Nothing hidden: report items automation cannot reach yet render as labeled manual rows, so the 18-section template stays complete.
